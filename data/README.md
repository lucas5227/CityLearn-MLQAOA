## 수행한 검증

- 모든 데이터 파일의 크기와 Git blob SHA-1을 고정 커밋의 GitHub 트리와 대조했습니다. 다운로드 후 SHA-256도 재검증했습니다.
- 세 스키마가 참조하는 CSV 파일이 모두 존재합니다.
- 각 스키마는 건물 17개, 3,600초 간격, 시뮬레이션 범위 0–8759를 지정합니다. 건물·기상·가격·탄소 집약도 CSV는 각각 8,760행입니다.
- 기본/DR 예제의 건물·기상·가격·탄소 집약도 파일은 동일합니다.
- EV 예제의 Building_1 및 가격은 기본 예제와 다릅니다. 기상·탄소 집약도는 같습니다. 공통 달력 열의 건물별 일치 여부는 0/17입니다. 공통 건물 이름만으로 물리적 동일성을 보장하지 않습니다.

- EV 예제에는 `start_date: 2024-08-01`이 있고 기본/DR 예제에는 없습니다. 실제 날짜 정합성을 검증하기 전 DR 이벤트를 EV 달력에 붙이지 마세요.

## 연구 사용 시 남은 확인

공식 예제에 EV 세션 파일이 있다는 사실은 실측 세션임을 의미하지 않습니다. 실측/생성 여부와 출처는 이번 다운로드에서 확정하지 않았습니다. 연구 계획의 “실제 EV 세션만 사용” 조건은 별도 출처 검증이 필요합니다.

단위는 DR CSV의 명시적 단위를 제외하면 CityLearn 3.2.0 데이터 계약과 설비 스키마로 확인해야 합니다. SOC·출발 마감·충전 출력·유연부하 실행가능성과 DR 공식 정산은 아직 검증하지 않았습니다. EV·DR 데이터는 통합하지 않았으며, 추후 통합본은 연구용 파생 데이터로 따로 표시해야 합니다.
